# Калькулятор UX/UI-проєкту

Готовий інструмент для розрахунку вартості UX/UI-проєкту. Працює на телефоні й десктопі, без сервера та залежностей.

- Адаптивний інтерфейс, світла/темна тема за системою
- Налаштування зберігаються в браузері (localStorage)
- Працює офлайн (PWA) і встановлюється на головний екран
- Кнопки «Копіювати пропозицію» / «Поділитись» для клієнта

## Використання

**Локально:** відкрий `index.html` у браузері.

**Онлайн (GitHub Pages):** Settings → Pages → Source: **GitHub Actions**, після злиття в `main` сайт буде за адресою `https://<user>.github.io/ux-ui-calculator/`.

**Встановлення на телефон:** відкрий посилання → Chrome: «Додати на головний екран» / Safari: «Поділитись → На початковий екран».
